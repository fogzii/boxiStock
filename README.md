## Database

This project uses **Supabase** as its data layer (not Prisma). Runtime DB access is handled via the Supabase JS client (`@supabase/supabase-js`) in `src/lib/supabase/server.ts`.

Schema changes should be applied directly via:
- Supabase SQL Editor (dashboard)
- Supabase MCP (AI-assisted migrations)
- Raw SQL in the Supabase migrations table

There is no ORM — queries are written with the Supabase PostgREST client (`.from(...)`/`.rpc(...)`) or raw SQL via `.rpc`.
